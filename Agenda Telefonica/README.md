# 📇 Agenda Telefônica

## 📄 Descrição

Este projeto simula uma agenda de contatos com operações CRUD (Criar, Listar, Atualizar e Remover). Os dados são armazenados em memória utilizando listas.

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- Console (Scanner)
- Listas (`ArrayList`)
- POO

---

## 🚀 Como Executar

```bash
javac src/AgendaTelefonica.java
java src.AgendaTelefonica
