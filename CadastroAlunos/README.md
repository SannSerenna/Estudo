# 🎓 Cadastro de Alunos

## 📄 Descrição

Sistema simples para cadastrar alunos, registrar notas e exibir uma lista com média de desempenho. O projeto roda em console.

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- Console (Scanner)
- POO

---

## 🚀 Como Executar

```bash
javac src/CadastroAlunos.java
java src.CadastroAlunos
