# ➕ Calculadora

## 📄 Descrição

Calculadora básica em Java com operações de adição, subtração, multiplicação e divisão. Usuário escolhe a operação pelo console.

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- Console (Scanner)

---

## 🚀 Como Executar

```bash
javac src/Calculadora.java
java src.Calculadora
