# 💰 Sistema Financeiro

## 📄 Descrição

Sistema em Java para registrar entradas e saídas financeiras, calculando o saldo final. Tudo feito via console com interação simples.

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- Console
- POO

---

## 🚀 Como Executar

```bash
javac src/Financeiro.java
java src.Financeiro
