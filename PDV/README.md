# 🛒 Sistema PDV (Ponto de Venda)

## 📄 Descrição

Simulação de um sistema de vendas no console: o usuário seleciona produtos, define quantidades e formas de pagamento. O total da compra é calculado ao final.

---

## 🛠️ Tecnologias Utilizadas

- Java 17+
- Console
- Estruturas condicionais
- Laços de repetição

---

## 🚀 Como Executar

```bash
javac src/PDV.java
java src.PDV
