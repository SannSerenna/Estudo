# ☕ Repositório de Estudos em Java

Este repositório reúne projetos práticos que desenvolvi durante meus estudos em Java.  
Cada projeto aborda conceitos diferentes, como Programação Orientada a Objetos, coleções, controle de fluxo, entrada de dados, cálculos e simulações de sistemas reais em console.

---

## 📚 **Projetos incluídos**

| Projeto | Descrição |
|----------------|------------------------------------------------------------------|
| **📇 Agenda Telefonica** | CRUD de contatos usando listas e interação via console. |
| **🎓 CadastroAlunos** | Sistema para cadastro de alunos com notas e média final. |
| **➕ Calculadora** | Calculadora com operações básicas matemáticas. |
| **💰 Financeiro** | Simulação de fluxo de caixa simples (entradas e saídas). |
| **🛒 PDV** | Simulação de um Ponto de Venda (seleção de produtos, pagamento). |

---

## 🔍 **Como usar**

Cada projeto possui um arquivo `README.md` dentro da sua própria pasta com:
- Descrição detalhada
- Tecnologias aplicadas
- Passo a passo para compilar e executar o código Java no console

**Acesse a pasta desejada e siga as instruções específicas!**
